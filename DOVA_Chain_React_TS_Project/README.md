# DOVA Chain — React + TypeScript frontend

This is a complete React + TypeScript/Vite conversion of the supplied DOVA Chain page. The page markup is real TSX (not `dangerouslySetInnerHTML`), the original styling is preserved, and the interactive behavior is implemented with React state/hooks.

## Run

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

## Included
- Responsive desktop, laptop, tablet and mobile layouts
- Mobile navigation menu
- Scroll reveal animations with reduced-motion support
- Featured Products category filtering
- Original DOVA colors, typography, cards, imagery and layout
- SEO metadata in `index.html`
- TypeScript strict mode
